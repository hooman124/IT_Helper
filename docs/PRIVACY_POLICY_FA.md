# سیاست حفظ حریم خصوصی IT Helper

آخرین به‌روزرسانی: ۱۴۰۵/۰۶/۲۹

IT Helper در نسخه فعلی برای قابلیت‌های اصلی عیب‌یابی، اطلاعات شخصی کاربر را جمع‌آوری یا به سرور ارسال نمی‌کند. محتوای اصلی برنامه به‌صورت محلی در برنامه قرار دارد.

اطلاعاتی که در آینده ممکن است برای قابلیت‌های اختیاری مانند خرید، آمار استفاده یا محتوای آنلاین پردازش شود، فقط پس از فعال‌سازی قابلیت مربوط و مطابق قوانین و سیاست‌های سرویس ارائه‌دهنده اعلام خواهد شد.

کاربر نباید اطلاعات حساس، رمز عبور، کلیدهای دسترسی یا اطلاعات محرمانه سازمانی را داخل برنامه وارد کند.

برای پرسش‌های مربوط به حریم خصوصی می‌توان از راه ارتباطی درج‌شده در صفحه برنامه استفاده کرد.
